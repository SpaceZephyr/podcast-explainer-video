# 口播稿怎么写

目标：看完有收获。观众不一定听过这期播客，要先知道「谁在聊、聊什么」，再拿走几个能复述的观点。

## 结构

| 段 | 写法 | 例 |
|---|---|---|
| 开场 | 谁 + 上了谁的节目，一句说完 | 最近听了一期挺有意思的播客：扎克伯格和 Meta 的首席 AI 官亚历山大·王，一起上了 Stripe 联合创始人科里森的节目 Cheeky Pint。 |
| 目录 | 聊了多久、主题，挑了几个点 | 两个人聊了两个多小时，讲 Meta 是怎么做前沿 AI 的。我挑了四个觉得最有启发的点，分享给大家。 |
| 每个点 | 结论 → 为什么/例子/数字 → 引出原声 → 原声 | 第一点，做前沿 AI，是反着来的创业。普通创业是先做一点，验证了再加钱；可数据中心要提前好几年建…… |
| 原声 | 中文译文 ≤ 20 字，忠实原意 | 困难模式的创业，跟精益创业正好相反。 |
| 收尾 | 把几个点串成一句 + 对谁有用 | 四点连起来看：先押注，留退路，把体验做进模型，再交给一支小而精的团队。 |

## 要点

- 每个点开头就给结论（「第 N 点，……」），观众随时进来都跟得上。
- 抽象的话后面紧跟具体东西：数字（一吉瓦一年 150 亿美元）、场景（训练馆的摄像头、60 秒休息）。
- 原声放在讲清楚之后，作为印证；引出句要短：「扎克伯格是这么说的。」
- 只用来源里有的事实；嘉宾背景、数字都要能在 facts.md 里找到出处。
- 人名用中文常见译名（扎克伯格、亚历山大·王），节目名保留英文。
- 不说「首先其次」「值得注意的是」「赋能」「闭环」，不排比、不升华。

## 字数

- 旁白一句 30–60 字，一句一场。
- IndexTTS2 每秒约 5 字，微软音色 +15% 每秒约 5.5 字；每场额外约 0.35 秒。
- 2 分钟 ≈ 旁白 550 字 + 原声 4 段（共 15–20 秒）。
