# 画面：版式、组件、写法

## 版式（1080×1920）

| 区域 | 位置 | 内容 |
|---|---|---|
| 大标题 `#hd` | top 300，80px，白字蓝影斜体 | config.title 两行，全片固定 |
| 画框 `.win` | left 40，top 560，1000×564，圆角 26 | 背景透明，compose.py 把原视频垫在下面；纯图解场自己铺深色底 |
| 旁白字幕 `#cap` | top 1185，52px 白字 | build.mjs 按标点切块、跟语音走；原声场由 dropcaps.py 去掉 |
| 出处 `#src` | top 1478，28px 灰 | config.source |

画框内坐标从画框左上角算（0–1000 × 0–564）。

## 原声场

`quote("s04")`：画框左上红色「原声 · 说话人」；画框内底部 110px 渐变条，黄底说话人标签 + 黄色中文一行（字号按字数 30–46px 自动缩）。译文超过 20 字就会太小，改稿。

## 组件（模板里已定义）

| 写法 | 用途 |
|---|---|
| `frame(c, 内部HTML, first)` | 每场外壳：标题 + 画框 + 出处；第一场 `first=true` 让标题弹出 |
| `pos(x, y, html, A(...))` | 画框内绝对定位 |
| `point(c, 1, "反着来的创业")` | 画框左上的观点角标（蓝色圆圈编号） |
| `<div ${A({..., cls: "name"})} style="left:..;top:..">` | 人名条（姓名 + 身份） |
| `panel("文字")` | 半透明深色卡片，放数字和要点 |
| `dim(c, .78)` | 压暗原视频，上面放目录卡/收尾卡 |
| `<span class="chip">` | 小胶囊标签（节目名、时长） |
| `class="big"` | 粗斜体大字（数字、结论） |

动画参数和 `c.at("关键词")` 同 ai-tujie-video：`fx` = up / pop / fade / wipe / draw / count，`at` 用旁白念到某词的时刻。`A()` 自带 class，元素上不要再写 `class=`，用 `cls`。

## 常用场景

| 场 | 画面 |
|---|---|
| 开场 | 三人全景 + 三个人名条 + 节目胶囊 |
| 目录 | 双人镜头压暗 + N 行编号观点逐条弹出 |
| 讲观点（抽象） | 纯图解：对比流程（普通创业 vs 前沿 AI）、三张卡片 + 一句结论 |
| 讲观点（数字） | 嘉宾说话镜头 + 一侧数字面板（支票金额滚动、一吉瓦一年 150 亿） |
| 讲故事 | 嘉宾说话镜头 + 一侧 2–3 个要点面板（训练馆 · 摄像头 / 60 秒 / 看录像给建议） |
| 原声 | `quote()` |
| 收尾 | 压暗 + N 个关键词方块依次弹出 + 一句话 |

## 镜头

- edl.json 里讲到谁就用谁说话的镜头；原声场的画面起点由 cut_quotes.py 自动对齐。
- 卡片放在画面空的一侧：双人镜头里左边说话就放右边，反之亦然；不要挡脸。
